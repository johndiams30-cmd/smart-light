Voice‑Controlled
Dual Lamps

Hands‑free lighting · Real‑time Firebase sync

This project is part of the practical training in programmed electronics within technical schools. It demonstrates how voice recognition, cloud synchronization and embedded logic can be combined to build an intuitive control system.

Two lamps are operated either by voice commands, touch buttons, or by clicking on the bulbs themselves. The state is shared in real‑time via Firebase.
